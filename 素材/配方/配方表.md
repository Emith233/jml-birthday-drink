# 9.17 调酒配方

每次选择三种不同材料，按组合匹配饮品。以下是当前 12 杯主线饮品：

| 饮品 | 三种材料 | 用途/感觉 |
| --- | --- | --- |
| 草莓晴雨 | 草莓 + 气泡水 + 薄荷 | 小猪章节，甜甜的雨后心情 |
| 月下薄荷 | 柠檬 + 薄荷 + 气泡水 | 德文猫章节，清凉神秘 |
| 蜂蜜咖啡 | 咖啡豆 + 奶油 + 蜂蜜 | 夜晚陪伴，温暖醇厚 |
| 蓝莓星河 | 蓝莓 + 星星糖 + 气泡水 | 梦幻、像一小片星空 |
| 桃桃奶盖 | 桃子 + 奶油 + 星星糖 | 轻柔可爱 |
| 深夜蜜语 | 咖啡豆 + 蜂蜜 + 星星糖 | 熬夜后的秘密谈话 |
| 橙樱日落 | 橙子 + 樱桃 + 薄荷 | 明亮、热闹、像落日 |
| 草莓薄荷 | 草莓 + 薄荷 + 柠檬 | 清爽活泼 |
| 蓝莓柠檬 | 蓝莓 + 柠檬 + 薄荷 | 酸甜、带一点侦探感 |
| 蜜桃暖阳 | 桃子 + 蜂蜜 + 橙子 | 柔软温暖 |
| 樱桃奶云 | 樱桃 + 奶油 + 星星糖 | 甜点般的生日快乐 |
| 生日彩虹 | 草莓 + 蓝莓 + 橙子 | 终章隐藏饮品 |

材料图标在 `调酒材料/独立版/`，饮品图标在 `饮品/独立版/`，完整映射见同目录的 `配方表-独立素材.json`。
